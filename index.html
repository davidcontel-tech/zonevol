Zones géographiques UAS du SIA

Le SIA publie gratuitement toutes les zones drones (aérodromes, CTR, zones P/R/D, parcs…) avec leurs gestionnaires et contacts, mises à jour tous les 28 jours (cycle AIRAC). BFV Prévol s'en sert pour lister les démarches exactes.

  • Sur le site du SIA, page Données zones géographiques UAS : ajoute le dernier cycle au panier (gratuit) et télécharge le ZIP.
  • Charge-le ici (gardé sur cet appareil), ou dépose-le sur GitHub dans un dossier data/ sous le nom uaszones.zip : il sera alors chargé pour tous les appareils.

Coller des NOTAM

Colle un ou plusieurs NOTAM bruts (copiés depuis SOFIA). La ligne Q) est lue pour placer le cercle sur la carte et vérifier s'il touche ta zone. Sépare les NOTAM par une ligne vide.
